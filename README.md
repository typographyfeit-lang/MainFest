# 🧱 Block Arena

Браузерная стратегия в реальном времени: колода из 8 карт, эликсир, по три башни у каждой стороны, трёхминутный бой против бота.

## Графика

- Стилизованная мультяшная 3D-графика (Three.js) с блочной «майнкрафтовской» геометрией и мягкими тенями
- Камера 2.5D: вид сверху под наклоном 52°, подведена максимально близко к арене
- Крупные бойцы с преувеличенными пропорциями: огромные головы, большие глаза, румяные щёки
- «Рисованные» пиксельные текстуры (трава, камень, доски, вода) генерируются кодом — внешних картинок нет

## Запуск

Нужны интернет (three.js подключается с cdnjs) и браузер с WebGL.
Откройте `index.html` или выполните `python3 -m http.server` и зайдите на http://localhost:8000.
Для работы офлайн скачайте `three.min.js` (r128) рядом с игрой и поправьте `src` в `index.html`.

## Правила

- Выберите карту внизу, затем нажмите на свою половину арены. Заклинания можно кидать в любую точку.
- Эликсир растёт сам, в последнюю минуту вдвое быстрее. Максимум — 10.
- Побеждает тот, кто разрушит больше башен. Король — сразу победа. При равенстве решает здоровье башен.
- Победа: +30 🏆 и 60 🪙. Монеты — на сундуки с новыми картами. Колода собирается во вкладке «Карты».

## Структура

- `index.html` — меню (Магазин / Карты / Бой / Клан) и экран боя
- `style.css` — оформление
- `game.js` — карты `CARDS`, логика боя, бот, интерфейс
- `render3d.js` — 3D-сцена: арена, башни, бойцы, анимации, камера

Старые файлы `arena-art.js`, `*.webp` и `index(1).html` больше не используются.
