# 🧱 Block Arena

Браузерная стратегия в реальном времени: колода из 8 карт, эликсир, по три башни у каждой стороны, трёхминутный бой против бота. Блочная пиксельная стилистика, чистый HTML/CSS/JS — без сборки и зависимостей.

## Запуск

Откройте `index.html` в браузере или выполните `python3 -m http.server` и зайдите на http://localhost:8000.

## Публикация на GitHub Pages

1. Создайте репозиторий и загрузите все файлы из папки.
2. Settings → Pages → Deploy from a branch → `main` / `(root)`.
3. Игра будет доступна по адресу `https://<ваш-ник>.github.io/<репозиторий>/`.

## Правила

- Выберите карту внизу, затем нажмите на свою половину арены, чтобы вызвать юнита. Заклинания можно кидать в любую точку.
- Эликсир восстанавливается сам, в последнюю минуту — вдвое быстрее. Максимум — 10.
- Побеждает тот, кто разрушит больше башен. Король — это сразу победа. При равенстве решает оставшееся здоровье башен.
- За победу: +30 🏆 и 60 🪙. Монеты тратятся в магазине на сундуки с новыми картами. Колоду собирают во вкладке «Карты». Прогресс хранится в `localStorage`.

## Структура

- `index.html` — меню (Магазин / Карты / Бой / Клан) и экран боя
- `style.css` — оформление
- `game.js` — данные карт `CARDS`, логика боя, бот, отрисовка

Чтобы добавить карту, допишите запись в `CARDS` (`game.js`) — она появится в коллекции и в магазине.
