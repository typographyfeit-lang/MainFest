# Block Arena 2.9 — Cinematic Graphics & Animation

Основа: `typographyfeit-lang/MainFest`, main @ `e242c668d15b8ec2bff17220c645904de9e6ab48`. Все 25 файлов базового пакета 2.8 сверены по Git blob SHA. Пакет предназначен для ручного обновления GitHub Pages; изменений в удалённом репозитории не выполнено.

## Установка на GitHub Pages

1. Распакуйте ZIP. Загрузите **все файлы из корня архива**, включая `.glb`, в корень `MainFest` (Upload files). Не помещайте их во вложенную папку.
2. Commit changes. Дождитесь успешного Pages build and deployment.
3. Откройте `https://typographyfeit-lang.github.io/MainFest/?v=29&quality=high` или `?v=29&debug=1` для автоматической графики и статистики.
4. Нажмите «В БОЙ». При первом запуске дождитесь загрузки десяти GLB; при ошибке загрузки можно повторить нажатием.

Пути в index.html настроены. Старый `hd-model-data.js` можно удалить из репозитория, но он больше не подключается; не нужно удалять его для работы игры. Локальный запуск требует HTTP: `python3 -m http.server 8000`, затем `http://localhost:8000`. `file://` не поддерживается из-за fetch бинарных моделей. Для Three.js r128 пока нужен CDN. Если получена доверенная оригинальная `three.min.js` r128, её можно разместить в корне и заменить только соответствующий script src в index.html. В пакет библиотека не включена (доступ к CDN в среде разработки заблокирован).

## Что изменилось в 2.9

- 8 оригинальных GLB бойцов (`*-unit.glb`): геометрия, UV, вершинный цвет, скелет с 5–8 костями и 6 стандартных glTF клипов на модель. Модели созданы программным моделированием, не в Blender. Вес каждой вершины закреплён за одной костью — это артикулированная стилизованная броня, не мягкая деформация кожи. Геометрия, материалы и клипы кешируются, у каждого юнита собственный скелет. В рантайме скелетные позы интерполируются, а переходы сглаживаются. Модели импортируемы в редакторы, поддерживающие glTF 2.0.
- `binary-models.js` — ограниченный декодер GLB для собственных файлов; `hd-models.js`, `character-models.js` — загрузка 2 корпусов и 8 бойцов напрямую по относительным URL. Нет активного дублирования башен в Base64. Подготовка ресурсов начинается в меню, игра запускается после завершения.
- `characters.js` — скелетное воспроизведение Idle, Walk, Attack, Hit, Death, Spawn; визуальная ориентация на цель. `game.js` — косметические сигналы атак/заклинаний и подтверждение размещения при отпускании пальца. Эликсир не расходуется при предпросмотре/отмене. Баланс CARDS, координаты/HP башен, награды, колода и localStorage ba1 сохранены.
- `render3d.js` — каменные фрагменты разрушения, цифры урона, различимые цветовые эффекты Искры, Метеорита, Мага и Беса; повторно используемые объекты. Финальная анимация боя до 0.7 с. В авто-режиме после снижения DPR до 1 длительное падение FPS отключает динамические тени и сокращает новые частицы; восстановление после устойчивого роста FPS. Не является замеренным приростом FPS.
- `towers.js` — два локальных цветных point light без собственных теней в High. Корпуса GLB и размеры 2.8 сохранены. `environment.js` — анимированный микрорельеф воды (кроме Low) и процедурная карта контактного затемнения у стен. Это не физическое запекание освещения, не шейдер рефракции и не постпроцессинговый Bloom.
- `build-character-models.py`, `build-hd-models.py` — воспроизводимые оригинальные модели; `character-budget.json`, `model-budget.json` — количество треугольников, размеры, анимации.

## Диагностика

`?v=29&quality=high&debug=1`: высокое качество, фиксированный пресет. `?v=29&debug=1`: автоматическое качество. `?v=29&quality=low`: облегчённый режим. `V.stats()` включает число загруженных моделей, FPS, DPR, draw calls, triangles, состояние адаптации теней. На iPhone необходимо отдельно измерить FPS на пустой арене и при 20–40 бойцах; реальные показатели ещё неизвестны.

## Тесты

- `python3 check-models.py`: проверка бинарной структуры, индексов, весов, обратных матриц и анимационных треков.
- `python3 check-camera.py`: аналитическая подгонка камеры; не реальный рендер.
- `python3 check-logic.py`: DOM/игровые правила, 5 ширин; V заглушен.
- `python3 check-runtime.py`: интеграция JavaScript с точными GLB ArrayBuffer через имитацию fetch и нерисующую замену Three.js. Не WebGL.
- `python3 check-webgl.py --quality medium`: настоящий браузерный WebGL-тест. Нужны Playwright, Chromium и доступ к оригинальному Three.js r128. С локальной копией `python3 check-webgl.py --three /path/to/three.min.js`. В среде подготовки не запустился из-за сетевого ограничения и блокировки браузерной навигации. Не считать визуальную приёмку или FPS подтверждёнными.

Следующие релизы: полный Spatial Hash, навигация вокруг башен, динамические LOD, локальная копия Three.js, тактический ИИ, прогрессия, новые арены. Они не входят в 2.9. Настоящее запечённое освещение, HDRI и выборочный Bloom требуют отдельной графической проверки.
