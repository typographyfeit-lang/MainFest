# BLOCK ARENA 2.7 — Crystal Sanctuary

Комплексное визуальное обновление 2.2–2.7 на основе репозитория `typographyfeit-lang/MainFest`, коммит `53ff5468be14619903b2e45af49a8381deb2cdd1` (версия 2.1).

## Установка через GitHub

1. Распаковать `block-arena-2.7.zip`.
2. Открыть https://github.com/typographyfeit-lang/MainFest/upload/main.
3. Выбрать все файлы из распакованного архива и загрузить непосредственно в корень репозитория, заменяя одноимённые файлы. Не загружать ZIP как отдельный файл. Не создавать папку `graphics/`.
4. Нажать Commit changes. После завершения GitHub Pages открыть https://typographyfeit-lang.github.io/MainFest/?v=27&quality=medium
5. Для более подробной графики: `?v=27&quality=high`; для менее мощного устройства: `?v=27&quality=low`.

`index.html` уже содержит правильный порядок подключения и версию ресурсов `?v=27` для уменьшения риска загрузки старого кеша. Не нужно редактировать его вручную. Старые WebP-файлы и `index(1).html` можно оставить; новый рендерер их не использует.

## Состав обновления

- 2.2 — корректное преобразование заданных sRGB-цветов в линейное пространство Three.js r128; экспозиция 0.94; более высокое положение ключевого света; насыщенные командные цвета; адаптивная камера 58–64°, FOV 22°, учёт объёма башен.
- 2.3 — увеличенные башни, усиленные силуэты, арочные окна, золотые архитектурные детали, более выразительные кристаллы, геометрия капюшона и знамён.
- 2.4 — тёмное внешнее окружение, каменные руины, контактное затемнение краёв, растения, усиленные руны, блики и отдельный анимированный слой каустики воды, заклёпки мостов.
- 2.5 — улучшенная геометрия персонажей и оружия, щиты, броня, плечевые элементы, анимация получения урона; на High сохраняются различные семейства материалов с UV в объединённых моделях.
- 2.6 — десять оригинальных векторных портретов карт (единый SVG-атлас), обновлённые рамки, стоимость карт, главное меню и HUD, шкала эликсира.
- 2.7 — шлейфы магических снарядов, анимированные знамёна, частицы, оригинальные синтезированные звуки призыва, атаки, заклинания, разрушения башни и результата боя, кнопка звука и вибрация на поддерживаемых устройствах.

## Файлы

`index.html`, `style.css`, `art.js`, `environment.js`, `towers.js`, `characters.js`, `audio.js`, `render3d.js`, `game.js`, `cards-v27.svg` — всё, что требуется для запуска. Файлы тестов и документация не подключаются в браузере.

Техническая архитектура остаётся процедурной Three.js r128. Новые оригинальные формы создаются посредством пользовательской геометрии, LatheGeometry, ExtrudeGeometry, instancing и объединения мешей. Внешние GLB-модели и Blender-файлы не включены. Это не финальная версия графических ассетов профессионального художника. Результат требует визуального сравнения на настоящем WebGL.

`game.js` сохранён побайтно; игровой баланс, бот, симуляция, награды, эликсир, колода и `ba1` не изменены. Звук хранит свою отдельную настройку `ba_audio_v27`.

## Локальный запуск и тесты

Нужны современный браузер с WebGL и доступ к CDN Three.js r128. Выполнить `python3 -m http.server 8000`, открыть http://localhost:8000. Допустимо скачать Three.js r128 локально и заменить только URL библиотеки в `index.html`.

Тесты: `python3 check-camera.py`; установить Playwright (`pip install playwright`, затем `python3 -m playwright install chromium`), выполнить `python3 check-logic.py` и `python3 check-runtime.py`. Последние два теста используют заглушки, не являются проверкой настоящего WebGL. Для полной проверки: `python3 check-webgl.py --quality medium` или `python3 check-webgl.py --three /path/to/three.min.js --quality high`.

Во время реального боя в консоли браузера `V.stats()` возвращает статистику рендерера. В данном пакете фактические FPS, draw calls и визуальный результат WebGL не измерены: CDN недоступен из среды разработки. См. `TEST_REPORT.md`.
