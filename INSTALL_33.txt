CRYSTAL DOMINION 3.3 — LIVING BATTLEFIELD
Обновление арены и боевого звука поверх опубликованной версии 3.2.

УСТАНОВКА НА GITHUB PAGES
1. Скачайте и распакуйте ZIP.
2. Откройте https://github.com/typographyfeit-lang/MainFest/upload/main
3. Загрузите ВСЕ файлы из архива непосредственно в корень main.
4. Подтвердите замену index.html, sw.js и manifest.webmanifest. Остальные файлы новые.
5. Не удаляйте старые ресурсы, модели, движок и меню 3.2.
6. Нажмите Commit changes. После успешного GitHub Pages откройте:
   https://typographyfeit-lang.github.io/MainFest/?v=33

ПРОВЕРКА НА ТЕЛЕФОНЕ
- Нажмите «В БОЙ». Звук активируется после взаимодействия с экраном.
- Проверьте свист стрел, удары, шаги, святилище и финальную минуту.
- Профиль → Оформление арены: Авто / Лёгкое / Статичное.
- Профиль → Звуковое оформление боя или Пауза → Громкость и вибрация.
- Громкость музыки боя, эффектов, окружения и возгласов настраивается отдельно.
- Общий переключатель звука сохраняет прежнее назначение. Музыка меню 3.2 не изменена.
- При паузе и уходе из игры боевые звуки и дорожки останавливаются.
- Вибрация работает только в поддерживающих её браузерах/устройствах.
- Режим Статичное отключает новые декоративные анимации, но сохраняет индикаторы игры.

Качество старого боевого рендера: ?v=33&quality=low / medium / high.
Переопределение новых эффектов арены: ?v=33&arena=light или arena=static.
Отладка: ?v=33&debug=1. Настоящий FPS проверяется на устройстве.

Если браузер показывает прежнее меню: обновите страницу, проверьте статус Pages,
закройте и снова откройте вкладку. Не очищайте данные сайта без резервного кода прогресса.

Важно: это патч для существующего MainFest 3.2, не самостоятельный дистрибутив.
Правила боя, прокачка, составы ботов, сохранения, GLB-модели и карта не перезаписываются.
См. TEST_REPORT_33.md для границ тестирования.
