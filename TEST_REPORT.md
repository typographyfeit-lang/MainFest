Решения: сохранена версия Three.js, процедурные модели, а также плоская структура репозитория. Вместо GLB/Blender применены дополнительные оригинальные геометрии и существующие PBR-материалы. Не утверждается, что обновление уже выглядит как исходный художественный референс. Ветка GitHub не изменялась — это готовый пакет для ручной установки.
