CRYSTAL DOMINION 3.4 — VISUAL OVERHAUL
Графический патч поверх MainFest 3.3.2 (коммит 5b7499a75e496768c52c441da0e53a6f3114983a).

УСТАНОВКА
1. Скачайте ZIP и распакуйте его в приложении «Файлы» на iPhone.
2. Откройте https://github.com/typographyfeit-lang/MainFest/upload/main
3. Загрузите ВСЕ файлы из архива в корень репозитория, а не сам ZIP и не папку.
4. Подтвердите Commit changes. Не удаляйте ни один старый файл: старые модели используются как резервные.
5. Убедитесь, что GitHub Actions → pages build and deployment завершилось успешно для нового коммита.
6. Откройте https://typographyfeit-lang.github.io/MainFest/?v=34&perf=auto&audio=auto&lobby=light&debug=1
   Если видна прежняя версия, закройте вкладку и откройте ссылку вновь после обновления кеша. Не очищайте данные сайта, иначе можно потерять локальный прогресс.

ГРАФИКА
- Страж и Колосс получили новые GLB, сохранены исходные скелеты, анимации, игровые характеристики.
- Новое ядро, гранёный кристалл и орнамент святилища, текстуры пола, камня и золота.
- 640 старых плит исключаются из отрисовки после успешной загрузки текстуры нового пола.
- Освещение перенастроено без дополнительных источников и теневых проходов.
- Сохраняются адаптивные эффекты, меню 3.2, звук и диагностика 3.3.2.
