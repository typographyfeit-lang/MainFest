CRYSTAL DOMINION 3.0 — УСТАНОВКА

1. Распакуйте crystal-dominion-3.0.zip.
2. Откройте https://github.com/typographyfeit-lang/MainFest/upload/main
3. Загрузите ВСЕ файлы из архива в корень (без папки). Согласитесь заменить одноимённые.
4. Commit changes. Проверьте завершение GitHub Pages Actions.
5. Откройте https://typographyfeit-lang.github.io/MainFest/?v=30
   High: https://typographyfeit-lang.github.io/MainFest/?v=30&quality=high
   Диагностика: https://typographyfeit-lang.github.io/MainFest/?v=30&debug=1

Редактировать index.html или удалять старые ресурсы не требуется.
Старый прогресс импортируется на том же устройстве/сайте. Ключ ba1 сохраняется.
Для запуска нужен доступ к Three.js CDN и WebGL. Реальный рендер ещё не проверен.
