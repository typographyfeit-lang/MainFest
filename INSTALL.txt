CRYSTAL DOMINION 3.1 — УСТАНОВКА

1. Распакуйте crystal-dominion-3.1.zip (на iPhone: приложение «Файлы», нажать на архив).
2. Рекомендуется сначала проверить в отдельной ветке: на GitHub откройте MainFest,
   Branch → создать ветку, например update-3.1, и загружайте в неё.
3. Откройте https://github.com/typographyfeit-lang/MainFest/upload/<ветка>
   (для main: https://github.com/typographyfeit-lang/MainFest/upload/main).
4. Загрузите ВСЕ 27 файлов из архива в корень (без папки), согласитесь заменить одноимённые.
   Commit changes. Модели .glb и cards-v27.svg уже лежат в репозитории и не менялись.
5. Если загружали в ветку: Pull request → проверить → Merge в main.
   GitHub Pages публикует main; дождитесь завершения Actions (обычно 1–2 минуты).
6. Откройте https://typographyfeit-lang.github.io/MainFest/?v=31
   Высокое качество: ?v=31&quality=high · Диагностика: ?v=31&debug=1

Если видна старая версия: обновите страницу ещё раз (игра кэширует файлы для офлайн-режима,
новая версия подхватывается при следующем запуске).

Прогресс 3.0 сохраняется (тот же ключ на том же устройстве). Старый ключ ba1 не трогается.
Three.js теперь лежит в репозитории, интернет-CDN больше не нужен.
