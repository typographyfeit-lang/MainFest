BLOCK ARENA 2.8 — ULTRA GRAPHICS EDITION
1. Распаковать ZIP в приложении «Файлы».
2. Открыть https://github.com/typographyfeit-lang/MainFest/upload/main
3. Загрузить ВСЕ распакованные файлы (не архив и не папку) в корень репозитория. Подтвердить замену старых файлов. Особенно важны index.html, hd-model-data.js, hd-models.js, render3d.js, game.js, art.js, towers.js, environment.js, style.css.
4. Нажать Commit changes, дождаться успешного развёртывания GitHub Pages.
5. Открыть https://typographyfeit-lang.github.io/MainFest/?v=28&quality=high
6. Для проверки FPS: https://typographyfeit-lang.github.io/MainFest/?v=28&debug=1
7. При низкой производительности открыть https://typographyfeit-lang.github.io/MainFest/?v=28&quality=low
Не редактировать index.html вручную. GLB продублированы в hd-model-data.js намеренно: это обеспечивает синхронную загрузку оригинальных моделей без стороннего загрузчика. Сетевой CDN Three.js всё ещё требуется. Сохранения ba1 совместимы с 2.7.
