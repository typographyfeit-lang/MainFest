CRYSTAL DOMINION 3.2 — LIVING SANCTUARY
Обновление меню для актуальной MainFest 3.1, не самостоятельная полная игра.
База: typographyfeit-lang/MainFest, commit b3560193e6231c2595ad3dc33dde06c120ce7476.

УСТАНОВКА С IPHONE
1. Сохрани ZIP в «Файлы», коснись архива для распаковки.
2. Открой https://github.com/typographyfeit-lang/MainFest/upload/main
3. Выбери ВСЕ файлы внутри распакованного архива, а не папку и не сам ZIP.
   Файлы должны находиться в корне MainFest рядом с game.js.
4. Подтверди замену index.html, manifest.webmanifest и sw.js. Остальные файлы новые.
5. Commit changes. Проверь завершение GitHub Pages во вкладке Actions.
6. Открой https://typographyfeit-lang.github.io/MainFest/?v=32
   Если открыто прежнее приложение, закрой его и открой повторно после публикации.
   Не очищай данные сайта: это может удалить сохранение.

ВАЖНО: не удаляй существующие файлы 3.1 — они необходимы для игры.
В архиве нет копий game.js, style.css, Three.js, GLB и других боевых ресурсов.
Они остаются в MainFest. Версии ?v=31 у прежних скриптов намеренно сохранены.
Ключ сохранения, формат сохранений, цены, прокачка, сложность и бой не менялись.

НАСТРОЙКИ В ПРОФИЛЕ
Авто · 2.5D — основной режим: фон, частицы, кристалл, хранитель, руны, свет.
Полная · 3D — динамическое вращение кристалла и скелетная Idle-анимация Колосса.
При недоступном WebGL или низкой производительности автоматически включается облегчение.
Лёгкая — ограниченное число частиц, без движущихся облаков, тумана и водопадов.
Статичная — без непрерывных анимаций. Учитывается настройка уменьшения движения ОС.
Музыка запускается после касания. Общая кнопка звука её тоже отключает.
В бою и при сворачивании анимации меню и музыка останавливаются.
