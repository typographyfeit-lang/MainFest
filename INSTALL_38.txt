CRYSTAL DOMINION 3.8 — ROYAL CITADELS

Требование: на сайте установлена версия 3.7 Imperial Sanctuary.
1. Распаковать ZIP.
2. Загрузить все файлы из архива в корень репозитория MainFest.
   Существующие index.html, sw.js, render3d.js и manifest.webmanifest заменить.
   Остальные файлы предыдущих версий НЕ удалять.
3. Выполнить Commit changes. Дождаться успешного GitHub Pages deploy.
4. Открыть https://typographyfeit-lang.github.io/MainFest/?v=38
   Если показывается старая версия, закрыть и снова открыть сайт или PWA.
   Не очищать данные сайта: прогресс хранится локально. Сначала экспортировать
   код прогресса в профиле, если требуется переустановка приложения.

Профиль → Камера арены · 3.8. Те же настройки доступны в паузе боя.
- Классическая: 60°, королевская: 66° (по умолчанию), тактическая: 76°.
- Наклон вручную 58–78°. Изменяется только обзор, не координаты призыва.
- Тряска выключена по умолчанию; кинематографичный финал включён.
- В Eco и при системном уменьшении движения финальный пролёт отключается.
- Параметры URL: camera=classic|royal|tactical, pitch=58..78.
- Для диагностики: ?v=38&camera=royal&perf=eco&quality=low&audio=media&lobby=light&debug=1
- Для прежнего оформления башен: ?v=38&citadel=legacy
- Для прежнего оформления и камеры: ?v=38&visual=legacy

Сохранения и баланс версии 3.7 не меняются. Патч не является полной копией
репозитория, старые GLB, звуки, текстуры, стили и скрипты нужны игре.
