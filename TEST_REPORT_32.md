# Crystal Dominion 3.2 — Living Sanctuary: проверка обновления

База: MainFest, `b3560193e6231c2595ad3dc33dde06c120ce7476`. Проверены актуальные `index.html`, `style.css`, `game.js`, `audio.js`, `art.js`, `character-models.js`, `render3d.js`, `binary-models.js`, `pwa.js`, `sw.js`, `manifest.webmanifest` и список файлов. Обновление является патчем интерфейса, а не полной отдельной копией игры. Существующие боевые файлы и ключ сохранения остаются без изменений.

## Новые ресурсы и решения

- Вертикальный оригинальный художественный фон, созданный для этого обновления, сжат в WebP.
- Слои CSS: водопады (анимированные блики), туман, облака, руническое кольцо, левитация кристалла, свечение, 20 магических частиц, блик кнопки, лёгкий параллакс при движении указателя. Растения находятся на статичном художественном фоне; отдельной анимации растений нет.
- В режиме 2.5D хранитель — программный растр существующей модели Колосса (`colossus-unit.glb`, Git blob `5806969288a5ae8c9c39558023c63132fec28170`) с анимацией CSS. Кристалл — векторный ресурс. В режиме «Полная · 3D» код создаёт отдельный прозрачный Three.js canvas с настоящей геометрией кристалла и скелетным Idle существующего Колосса. Модель не заменялась и не считается новым уникальным персонажем.
- При смене раздела, скрытии страницы и запуске боя 3D-сцена освобождается. Если 3D недоступно, остаются 2.5D-слои. Автоматический режим по умолчанию не создаёт дополнительный WebGL-контекст. Облегчённый и статичный режимы доступны в профиле.
- Тематические баннеры отряда, кузницы и профиля — композиционные фрагменты общего нового фона с цветовой обработкой, не отдельные полноэкранные 3D-локации.
- Оригинальная синтезированная фоновая композиция: 32 секунды, MP3, стерео, локальный файл. Управление связано с общей кнопкой звука и отдельным выключателем музыки. Отдельные музыкальные файлы сторонних исполнителей не используются.
- Оригинальные правила доступны в раскрывающемся разделе «Как играть». Панель текущего отряда синхронизируется с существующим DOM. Роли рун берутся из действующих описаний. Не добавлены задания, новые бойцы или изменения баланса.
- Service worker меняет версию кэша на `crystal-dominion-32-living-sanctuary` и включает 40 URL. Существующие скрипты и GLB намеренно используют `?v=31`. Для аудио реализована обработка запросов диапазонов байтов.

## Ограничения

В тестовой среде `http://127.0.0.1` блокируется браузером, а попытка создать настоящий WebGL-контекст через Chromium/SwiftShader завершилась ошибкой `Error creating WebGL context`. Поэтому для HTML/CSS использован браузерный предпросмотр с встроенными локальными ресурсами и тестовыми данными профиля/отряда; это рендер реального нового интерфейса, но не скриншот игры, запущенной на GitHub Pages. Работа боевого движка в этом тесте не имитирует реальный бой. Динамический 3D-режим, реальное воспроизведение музыки в Safari, фактическая установка и офлайн-запуск PWA, FPS, нагрев и батарея на iPhone не подтверждены. Необходимы тесты после публикации. Репозиторий не изменён.
