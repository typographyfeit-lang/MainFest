CRYSTAL DOMINION 3.5 — ENCHANTED KINGDOM

Патч поверх опубликованной 3.4 Visual Overhaul.
База: MainFest, коммит f28672e7680d4ef1b14073a6ab1cfeb0bbb68282.

1. Распакуйте архив. Загрузите ВСЕ файлы архива непосредственно в корень репозитория:
   https://github.com/typographyfeit-lang/MainFest/upload/main
2. Не удаляйте ранее загруженные файлы игры. Существующие index.html и sw.js нужно заменить.
3. Commit changes; проверьте успешное завершение GitHub Pages для нового коммита.
4. Откройте https://typographyfeit-lang.github.io/MainFest/?v=35&perf=auto&debug=1
   Если видна старая версия, откройте игру в новой вкладке, обновите страницу после публикации.
   Не удаляйте данные сайта без резервного кода прогресса из профиля.

Зал коллекции: Отряд → Зал коллекции. Выберите руну или облик хранителя. «Вращение», «Атака», «Звук».
Облик хранителя: Профиль → Зачарованное королевство → Облик хранителя.
Все четыре облика бесплатны и косметические. Применяются к бонусному хранителю святилища, обычный Колосс не меняется.
При недоступном 3D отображается портрет. Старый Колосс используется в бою при ошибке загрузки облика.
Профиль: включение/выключение вступительной панорамы, смены времени суток; летопись развития.
В режиме совместимого звука для iPhone вступление ждёт кнопки «Начать бой» для пользовательского жеста.
Улучшения рун и получение осколков работают по прежним правилам; новая анимация только показывает результат.
Для сравнения старой 3D-графики: ?v=35&visual=legacy&debug=1
Экономичный режим: ?v=35&quality=low&perf=eco&lobby=light&audio=auto&debug=1

Сохранения (crystal-dominion-v1), звук 3.3.2 и код механики боя не изменены.
Выбранный облик и настройки атмосферы сохраняются отдельно в localStorage этого браузера; старый код CD1 не переносит их.
Версии 3.6–4.0 — дорожная карта, а не включённые новые миры или сюжет.
Физический iPhone и полноценный WebGL-бой не проверены. При лаге используйте экономичный режим и сообщите FPS/p95.
